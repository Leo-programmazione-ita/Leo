dati_binari(valore, formato = "testo")#

Una sequenza di byte (numeri da 0 a 255) comoda da maneggiare.

valore può essere un testo, una lista di byte o altri dati binari. Il formato dice come leggere un testo: "testo" (le lettere in UTF-8), "esadecimale", "base64", "base32", "base85", "bit" o "file" (il testo è il percorso di un file da leggere). Proprietà: lunghezza. Metodi: pezzo, unisci, cerca, in_lista, in_testo, codifica, leggi_numero, salva.

numero_in_byte(numero, byte = nulla, ordine = "piccolo", con_segno = falso)#

Un numero scritto come byte.

È il contrario di dati.leggi_numero(...). Un intero usa 4 byte se non dici altro, un decimale 8. ordine è "piccolo" (prima il byte meno importante) o "grande". Per i negativi serve con_segno = vero.

vista_esadecimale(sorgente, quanti = 256, da = 0)#

I byte di un file (o di dati) in righe leggibili, come hexdump.

Ogni riga mostra la posizione, 16 byte in esadecimale e le lettere stampabili (gli altri byte sono .). sorgente è il percorso di un file, una lista di byte o dei dati binari.

entropia_file(percorso)#

Quanto sono "disordinati" i byte di un file, da 0 a 8 (bit per byte).

Un testo sta intorno a 4-5; un file compresso (ZIP, JPEG, MP3) o cifrato arriva quasi a 8. Un file di documenti con entropia vicina a 8 e un nome strano può essere stato cifrato da un virus (ransomware).

leggi_exif(percorso)#

I metadati EXIF di una foto (JPEG, PNG, WebP, TIFF) in un dizionario.

Chiavi possibili: "marca", "modello", "programma", "data_scatto", "data_modifica", "autore", "copyright", "orientamento", "larghezza", "altezza", "esposizione", "diaframma", "iso", "focale", "obiettivo" e "gps" (un dizionario con "latitudine", "longitudine", "altitudine", "mappa"). Se la foto non ha metadati il dizionario è vuoto. ATTENZIONE alla privacy: la posizione GPS dice dove è stata scattata la foto (per

togli_exif(percorso, destinazione = nulla)#

Toglie da una foto i metadati (EXIF, GPS, XMP, commenti).

L'immagine resta identica: si tolgono solo le informazioni nascoste. Funziona con JPEG, PNG e WebP. Senza destinazione sostituisce il file stesso. Restituisce quanti blocchi di metadati ha tolto (0 se la foto era già pulita). Nota: la foto perde anche l'"orientamento", quindi alcune potrebbero apparire ruotate.

comprimi_dati(dati, metodo = "gzip")#

I dati compressi (più piccoli), come dati binari.

Metodi: "gzip" (il più diffuso), "zlib", "bz2", "xz" (il più piccolo, ma più lento). Un testo che si ripete si comprime tanto; una foto JPEG o un file ZIP quasi niente (sono già compressi).

decomprimi_dati(dati)#

Il contrario di comprimi_dati; il metodo si riconosce da solo.

Riconosce gzip, zlib, bz2 e xz. Si ferma se il risultato supera 256 MB (i file "bomba" minuscoli che diventano enormi servono a bloccare i computer).

cifra_testo(dati, password)#

Cifra un testo (o dei byte) con una password; il risultato è un testo illeggibile.

Usa AES-256-GCM, un cifrario vero, con la chiave ricavata dalla password con scrypt: chi non conosce la password non può leggere né modificare di nascosto il messaggio. Ogni volta il risultato è diverso (è normale). Serve il pacchetto cryptography. Se dimentichi la password i dati sono persi per sempre.

decifra_testo(testo, password, come_byte = falso)#

Rimette in chiaro un testo di cifra_testo.

Con la password sbagliata (o se qualcuno ha cambiato anche una sola lettera) dà un errore. Con come_byte = vero restituisce dati binari invece di un testo.

cifra_file(percorso, password, destinazione = nulla, sovrascrivi = falso)#

Cifra un file con una password.

Crea un file nuovo (di solito con ".leocifrato" in fondo al nome) e lascia com'è l'originale: cancellalo tu quando hai controllato che decifra_file funziona. Usa AES-256-GCM (serve il pacchetto cryptography). Restituisce il percorso del file cifrato.

decifra_file(percorso, password, destinazione = nulla, sovrascrivi = falso)#

Il contrario di cifra_file.

Senza destinazione toglie ".leocifrato" dal nome (se il file esiste già serve sovrascrivi = vero). Restituisce il percorso del file decifrato.

crea_chiavi_firma()#

Una nuova coppia di chiavi per le firme digitali Ed25519, in un dizionario.

"privata" serve a firmare e va tenuta segreta (come una password); "pubblica" si dà a tutti e serve a controllare che i tuoi file o messaggi vengano proprio da te e non siano stati cambiati. Serve il pacchetto cryptography.

firma_dati(dati, chiave_privata)#

La firma digitale (un testo) di un testo o di dati binari.

Chi ha la tua chiave pubblica controlla la firma con verifica_firma. Per firmare un file: firma_dati(dati_binari("programma.zip", "file"), chiavi["privata"]).

verifica_firma(dati, firma, chiave_pubblica)#

Vero se la firma è stata fatta con la chiave privata giusta

su proprio questi dati.

Falso se anche un solo byte dei dati o della firma è cambiato, o se ha firmato qualcun altro.

impronta_cartella(cartella)#

L'impronta SHA-256 di ogni file di una cartella (anche nelle sottocartelle).

Restituisce un dizionario percorso -> impronta (i percorsi sono relativi alla cartella, con /). Salvalo con scrivi_json e più avanti confrontalo con confronta_impronte per sapere che cosa è cambiato.

confronta_impronte(prima, dopo)#

Che cosa è cambiato tra due "fotografie" di una cartella.

prima e dopo sono dizionari di impronta_cartella (o dopo è direttamente il nome della cartella). Restituisce un dizionario con le liste "aggiunti", "tolti", "cambiati", il numero "uguali" e "intatta" (vero se non è cambiato niente).

cifrario_cesare(testo, spostamento = 3)#

Il cifrario di Giulio Cesare. SOLO PER GIOCO: NON È SICURO.

Ogni lettera (A-Z) va avanti di spostamento posti nell'alfabeto; le altre restano uguali. Per decifrare usa lo spostamento negativo. Ci sono solo 26 chiavi: prova_tutti_cesare le prova tutte in un attimo. Per i segreti veri usa cifra_testo.

cifrario_vigenere(testo, chiave, decifra = falso)#

Il cifrario di Vigenère. SOLO PER GIOCO: NON È SICURO.

Come Cesare, ma lo spostamento cambia a ogni lettera seguendo le lettere della chiave (A = 0, B = 1...). Si rompe contando le lettere che si ripetono (metodo di Kasiski, 1863). Per i segreti veri usa cifra_testo.

prova_tutti_cesare(testo)#

Mostra perché il cifrario di Cesare è debole, provando tutte le 26 chiavi.

Oggetto «dati_binari»

Valore Leo di tipo dati_binari: una sequenza immutabile di byte.

ProprietàSignificato
lunghezza

.cerca(sequenza, da = 0)#

La posizione della prima volta che compare sequenza, o nulla.

.codifica(formato = "esadecimale", separatore = "")#

I byte scritti come testo in un formato.

Formati: "esadecimale", "base64", "base32", "base85", "bit" (8 zeri e uni per byte). Il separatore va tra un byte e l'altro (solo per "esadecimale" e "bit").

.in_lista()#

I byte come lista di numeri da 0 a 255.

.in_testo(codifica = "utf-8")#

I byte letti come lettere di un testo.

Altre codifiche: "latin-1", "cp1252" (Windows), "utf-16", "ascii".

.leggi_numero(posizione = 0, byte = 4, ordine = "piccolo", con_segno = falso, decimale = falso)#

Legge un numero.

Legge byte byte a partire da posizione. ordine è "piccolo" (prima il byte meno importante, come nei PC, nei WAV e nei BMP) o "grande" (come in rete e nei PNG); con_segno = vero per i numeri che possono essere negativi; decimale = vero per i decimali (2, 4 o 8 byte).

.pezzo(inizio, fine = nulla)#

I byte da inizio (compreso) a fine (escluso), come nuovi dati binari.

I numeri negativi contano dalla fine.

.salva(percorso, sovrascrivi = vero)#

Scrive i byte in un file e restituisce quanti sono.

.unisci(altri...)#

Questi dati seguiti da altri (testi, liste di byte o dati binari).
