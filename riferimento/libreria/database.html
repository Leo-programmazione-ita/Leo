Database

Database SQLite: tabelle, ricerche e dati che restano.

  • 55 voci
  • 1 voci con esempi eseguiti

Funzioni 4

  • apri_database
  • crea_database
  • database_di_esempio
  • e_database

apri_database(percorso = ":memory:")#

Apre un database SQLite (lo crea se il file non c'è).

Senza percorso il database vive solo in memoria e sparisce alla fine del programma.

crea_database(percorso = ":memory:")#

Sinonimo di apri_database.

Se il file esiste già lo apre senza cancellare niente.

database_di_esempio()#

Un database in memoria già pieno, per fare prove senza rompere niente.

Ha le tabelle classi (nome, aula), alunni (nome, cognome, classe_id, nato) e voti (alunno_id, materia, voto); sparisce alla fine del programma.

e_database(percorso)#

vero se il file esiste ed è un database SQLite.

Oggetto «database»

Un database SQLite aperto da un programma Leo.

ProprietàSignificato

.aggiorna(tabella, condizioni, valori, tutte = falso)#

Cambia i valori delle righe scelte.

Restituisce quante righe sono cambiate. Senza condizioni serve tutte = vero (protezione contro gli sbagli).

.aggiungi_colonna(tabella, nome, tipo = "testo", predefinito = nulla)#

Aggiunge una colonna a una tabella che esiste già.

Le righe che ci sono già ricevono il valore predefinito (o nulla). Una colonna obbligatorio ha bisogno di un predefinito.

.annulla()#

Annulla le modifiche fatte da inizia_transazione() in poi.

.cerca(tabella, condizioni = nulla, ordina = "", limite = 0)#

Le righe che rispettano le condizioni.

Il risultato è una lista di dizionari. Condizioni: {"nome": "Ada"} (uguale), {"età": [">", 18]}, {"nome": ["contiene", "an"]}, {"voto": ["tra", 18, 30]}, {"città": ["in", ["Roma", "Milano"]]}; più condizioni valgono tutte insieme. Le condizioni di uguaglianza si possono scrivere anche per nome: db.cerca("alunni", classe = "5A"). Ordinamento: "nome", "età discendente", "cognome, nome".

.cerca_testo(tabella, testo, colonne = nulla, ordina = "", limite = 0)#

Le righe che contengono le parole cercate.

Ogni parola deve comparire in almeno una colonna; maiuscole e accenti non contano ("citta" trova "Città"). Senza colonne cerca in tutte le colonne di testo.

.chiudi()#

Chiude il database (le modifiche sono già salvate). Chiamarlo due volte non è un errore.

.colonne(tabella)#

Dizionario colonna -> tipo (per esempio {"id": "intero", "nome": "testo"}).

.compatta()#

Riordina il file del database e lo rende più piccolo dopo tante cancellazioni.

Restituisce quanti byte ha risparmiato (0 per un database in memoria).

.conferma()#

Salva le modifiche della transazione aperta con inizia_transazione().

.conta(tabella, condizioni = nulla)#

Quante righe rispettano le condizioni (tutte, senza condizioni).

.conta_per(tabella, colonna, condizioni = nulla)#

Dizionario valore -> quante righe hanno quel valore.

.copia_di_sicurezza(percorso)#

Salva una copia completa del database in un altro file.

Funziona anche mentre il database è in uso; le modifiche di una transazione non ancora confermata non entrano nella copia. Restituisce il percorso.

.copia_tabella(origine, nuova, condizioni = nulla)#

Crea nuova con le stesse colonne e ci copia le righe.

Restituisce quante righe ha copiato; con le condizioni copia solo quelle righe.

.crea_indice(tabella, colonne, unico = falso)#

Rende più veloci le ricerche su quelle colonne.

Con unico = vero impedisce anche i valori ripetuti. Restituisce il nome dell'indice. Serve con tabelle grandi (migliaia di righe).

.crea_tabella(nome, colonne)#

Crea la tabella se non c'è già.

colonne è un dizionario nome -> tipo: intero, decimale, testo, logico, seguiti se vuoi da chiave, obbligatorio, unico. Se non c'è una colonna id Leo ne aggiunge una automatica.

.distinti(tabella, colonna, condizioni = nulla)#

I valori diversi di una colonna, in ordine, senza ripetizioni.

I valori vuoti (nulla) non ci sono.

.elimina(tabella, condizioni, tutte = falso)#

Cancella le righe scelte e dice quante erano.

Senza condizioni serve tutte = vero (oppure usa svuota).

.elimina_duplicati(tabella, colonne = nulla)#

Toglie le righe ripetute (tiene la prima) e dice quante ha tolto.

Due righe sono ripetute se hanno uguali tutte le colonne (tranne l'id), oppure le colonne indicate.

.elimina_tabella(nome)#

Cancella la tabella con tutte le sue righe.

Restituisce vero se la tabella c'era, falso se non esisteva.

.esegui(sql, parametri = nulla)#

Esegue un comando SQL e restituisce le righe (lista di dizionari).

I valori vanno SEMPRE nei parametri, mai incollati nel testo: ? con una lista oppure :nome con un dizionario.

.esiste(tabella, condizioni = nulla)#

vero se c'è almeno una riga che rispetta le condizioni.

.esiste_tabella(nome)#

vero se nel database c'è la tabella nome.

.esporta_csv(tabella, percorso, separatore = ",", condizioni = nulla, ordina = "")#

Salva le righe in un file CSV.

La prima riga del file ha i nomi delle colonne. Restituisce quante righe ha scritto.

.esporta_json(tabella, percorso, condizioni = nulla, ordina = "")#

Salva le righe in un file JSON (lista di dizionari).

Restituisce quante righe ha scritto; le date diventano testi come "25/09/2026".

.importa_csv(percorso, tabella, separatore = nulla)#

Aggiunge alla tabella le righe di un file CSV.

La prima riga del file deve avere i nomi delle colonne. Se la tabella non c'è la crea, indovinando i tipi (intero, decimale, logico o testo). Tutto o niente: con una riga sbagliata non inserisce nulla. Restituisce quante righe ha aggiunto.

.importa_json(percorso, tabella)#

Aggiunge alla tabella le righe di un file JSON (la crea se non c'è).

Il file deve contenere una lista di dizionari (come quelli scritti da esporta_json). Tutto o niente. Restituisce quante righe ha aggiunto.

.importa_righe(tabella, righe)#

Aggiunge alla tabella una lista di dizionari (la crea se non c'è).

Se la tabella non esiste Leo la crea indovinando i tipi (intero, decimale, logico, data, testo). Va anche una lista di liste con i nomi delle colonne nella prima. Tutto o niente. Restituisce quante righe ha aggiunto.

.inizia_transazione()#

Da qui le modifiche restano in sospeso fino a conferma() o annulla().

.inserisci(tabella, riga)#

Aggiunge una riga e restituisce il suo id.

riga è un dizionario colonna -> valore; con una lista di dizionari le inserisce tutte (tutte o nessuna, se una è sbagliata) e restituisce la lista degli id.

.inserisci_o_aggiorna(tabella, riga, chiave = "id")#

Aggiorna la riga con la stessa chiave, oppure la aggiunge.

chiave è la colonna (o la lista di colonne) che riconosce la riga. Restituisce l'id della riga.

.massimo(tabella, colonna, condizioni = nulla)#

Il valore più grande della colonna (nulla se non ci sono righe).

.media(tabella, colonna, condizioni = nulla)#

La media dei numeri di una colonna (nulla se non ci sono righe).

I valori vuoti non contano.

.minimo(tabella, colonna, condizioni = nulla)#

Il valore più piccolo della colonna (nulla se non ci sono righe).

Funziona con numeri, testi (ordine alfabetico) e date.

.pagina(tabella, numero, per_pagina = 10, condizioni = nulla, ordina = "")#

Le righe della pagina numero (da 1).

Serve per mostrare tante righe un po' alla volta.

.primo(tabella, condizioni = nulla, ordina = "")#

La prima riga trovata, o nulla se non ce n'è.

.raggruppa(tabella, per, calcola = {"quanti": "conta"}, condizioni = nulla, ordina = "")#

Un riassunto per gruppi.

per è la colonna (o la lista di colonne) che forma i gruppi; calcola dice cosa calcolare per ogni gruppo: nome del risultato -> "conta", "somma COLONNA", "media COLONNA", "minimo COLONNA", "massimo COLONNA" o "distinti COLONNA". Il risultato è una lista di dizionari.

.riga(tabella, id)#

La riga con quell'id (la chiave della tabella), o nulla se non c'è.

.riga_a_caso(tabella, condizioni = nulla)#

Una riga scelta a caso (o nulla se non ce ne sono).

Ottima per i quiz.

.rinomina_colonna(tabella, vecchio, nuovo)#

Cambia il nome di una colonna (i valori restano).

.rinomina_tabella(vecchio, nuovo)#

Cambia il nome di una tabella (le righe restano).

.somma(tabella, colonna, condizioni = nulla)#

La somma dei numeri di una colonna (0 se non ci sono righe).

.stampa_tabella(tabella, condizioni = nulla, ordina = "", limite = 20)#

Stampa le righe come una tabella con i bordi.

Al posto del nome della tabella puoi dare una lista di righe (per

.struttura(tabella)#

Com'è fatta la tabella, colonna per colonna (lista di dizionari).

Ogni dizionario ha nome, tipo, obbligatorio, unico, chiave, collegata (la tabella collegata o nulla) e predefinito.

.svuota(tabella)#

Cancella tutte le righe della tabella (la tabella resta) e dice quante erano.

.tabelle()#

I nomi delle tabelle, in ordine alfabetico.

.transazione(azione)#

Esegue la funzione azione tutta o niente.

Se dentro azione c'è un errore, tutte le modifiche fatte fin lì vengono annullate e l'errore prosegue; altrimenti vengono salvate. Restituisce il risultato di azione.

.trova(tabella, condizioni = nulla, ordina = "", limite = 0)#

Sinonimo di cerca.

.ultimo(tabella, condizioni = nulla, ordina = "")#

L'ultima riga (l'ultima inserita, o l'ultima nell'ordine dato).

Restituisce nulla se non ci sono righe.

.unisci(tabella, altra, collega = nulla, condizioni = nulla, ordina = "", limite = 0, anche_senza = falso)#

Unisce le righe collegate di due tabelle.

Ogni riga di tabella si unisce alla riga di altra a cui è collegata. Leo trova da solo il collegamento se una colonna è collegato ALTRA oppure si chiama come classe_id (per la tabella classi); altrimenti scrivi collega = {"colonna_di_tabella": "colonna_di_altra"}. .valore_sql(sql, parametri = nulla)#

Esegue un comando SQL e restituisce un solo valore (la prima colonna della prima riga).

Restituisce nulla se non ci sono righe. Come in esegui, i valori vanno nei parametri ?.

.valori(tabella, colonna, condizioni = nulla, ordina = "")#

La lista dei valori di una sola colonna.
