Tabelle di dati

Tabelle come nei fogli di calcolo: filtri, ordinamenti, raggruppamenti e totali.

  • 41 voci
  • 4 voci con esempi eseguiti

Funzioni 5

  • tabella
  • tabella_da_csv
  • tabella_da_database
  • tabella_da_file
  • tabella_da_json

tabella(dati = nulla, colonne = nulla)#

Crea una tabella di dati con righe e colonne.

dati può essere una lista di dizionari (uno per riga), una lista di liste (la prima riga sono i nomi delle colonne, oppure li dai con colonne) o un dizionario di colonne.

tabella_da_csv(testo, separatore = nulla)#

Crea una tabella da un testo CSV (la prima riga sono i nomi delle colonne).

Il separatore (, ; o tabulazione) si indovina da solo, i numeri diventano numeri e le celle vuote diventano nulla.

tabella_da_json(testo)#

Crea una tabella da un testo JSON (una lista di oggetti, uno per riga).

tabella_da_file(percorso, separatore = nulla)#

Legge una tabella da un file CSV (anche salvato da Excel) o JSON.

Il tipo si capisce dall'estensione (.csv, .tsv, .txt, .json). Le celle vuote diventano nulla.

tabella_da_database(database, nome_o_sql, parametri = nulla)#

Crea una tabella da una tabella di un database SQLite o da una ricerca SQL.

database è un database aperto con apri_database oppure il percorso del file.

Oggetto «tabella»

Una tabella di dati: colonne con un nome, tutte lunghe uguali.

ProprietàSignificato
numero_colonne
numero_righe

.accoda(altra)#

Una tabella con le righe di questa e poi quelle dell'altra (le colonne si uniscono).

.aggiungi_colonna(nome, valori)#

Una tabella con una colonna in più (o cambiata, se c'è già).

valori è una funzione che riceve la riga e calcola la cella, una lista (un valore per riga) o un valore solo, uguale per tutte le righe.

.aggiungi_riga(riga)#

Aggiunge una riga in fondo alla tabella (cambia proprio questa tabella).

La riga è un dizionario (le colonne che mancano restano nulla, quelle nuove si aggiungono) oppure una lista con un valore per colonna.

.campione(quante = 5, seme = nulla)#

Alcune righe scelte a caso (con seme sempre le stesse).

.cerca(testo, colonne = nulla)#

Le righe in cui una cella contiene il testo (senza badare alle maiuscole).

.colonna(nome, senza_mancanti = falso)#

I valori di una colonna, come lista.

Con senza_mancanti = vero le celle vuote restano fuori (comodo per i calcoli).

.colonne()#

La lista dei nomi delle colonne.

.conta_valori(colonna)#

Quante volte compare ogni valore della colonna, dal più frequente.

Il risultato ha le colonne: il valore, conteggio e percentuale.

.copia()#

Una copia della tabella (cambiare la copia non cambia l'originale).

.filtra(condizione, operatore, valore)#

Una tabella con solo le righe che rispettano la condizione.

Operatori: = != < <= > >= contiene, inizia con, finisce con, in, non in, tra, mancante.

.grafico(tipo = "barre", etichette = nulla, valori = nulla, titolo = "")#

Un grafico con i dati della tabella.

etichette è la colonna dei nomi sull'asse, valori una colonna di numeri (o una lista di colonne, per più serie). Senza valori conta quante volte compare ogni etichetta. Per "istogramma" basta una colonna di numeri; per "dispersione" le colonne x e y.

.in_csv(separatore = ",")#

La tabella come testo CSV (la prima riga sono i nomi delle colonne).

.in_html(titolo = "")#

La tabella come testo HTML (<table>...</table>), da mettere in una pagina.

.in_json()#

La tabella come testo JSON (una lista di oggetti, uno per riga).

.mancanti()#

Un dizionario che dice, per ogni colonna, quante celle sono vuote.

.mostra(righe = 20)#

Scrive la tabella allineata, al massimo con quel numero di righe.

.ordina(colonne, decrescente = falso)#

Una tabella con le righe in ordine secondo una o più colonne.

I testi vanno in ordine alfabetico (senza badare alle maiuscole), le celle vuote sempre in fondo.

.prime(quante = 5)#

Una tabella con solo le prime righe.

.raggruppa(colonne, calcoli = nulla)#

Una riga per ogni gruppo, con i calcoli sulle altre colonne.

calcoli è un dizionario colonna -> calcolo ("somma", "media", "mediana", "conta", "minimo", "massimo", "primo", "ultimo", "elenco", "diversi"), anche più di uno con una lista. Le colonne nuove si chiamano come "media_voto". Senza calcoli conta le righe di ogni gruppo.

.riassumi()#

Una tabella con le statistiche di ogni colonna.

Per ogni colonna: tipo, valori pieni, mancanti, valori diversi, minimo, massimo, media e somma (queste ultime due solo per le colonne di numeri).

.riempi_mancanti(valore, colonne = nulla)#

Una tabella in cui le celle vuote hanno quel valore.

Con un dizionario si sceglie un valore per colonna: t.riempi_mancanti({"voto": 0, "note": "-"}).

.riga(indice)#

Una riga come dizionario (la prima è la riga 0, l'ultima è -1).

.righe()#

Tutte le righe, come lista di dizionari (colonna -> valore).

.rinomina(vecchio, nuovo)#

Una tabella con una colonna che ha un nome nuovo.

Per cambiarne tante insieme usa un dizionario: t.rinomina({"nm": "nome", "vt": "voto"}).

.salva(percorso, excel = falso)#

Salva la tabella in un file; il formato dipende dall'estensione.

.csv (con excel = vero pronto per l'Excel italiano: ; e virgola decimale), .tsv, .json, .html (una pagina da aprire nel browser) o .md. Restituisce il percorso.

.salva_in_database(database, nome, sostituisci = falso)#

Copia le righe in una tabella di un database SQLite.

Se la tabella del database non c'è, si crea con i tipi giusti; se c'è si aggiungono le righe (con sostituisci = vero prima si cancella). database è un database aperto o un percorso.

.seleziona(colonne...)#

Una tabella con solo le colonne scelte, nell'ordine scelto.

.statistiche(colonna)#

Un dizionario con i numeri principali di una colonna.

Chiavi: "conta" (celle piene), "mancanti", "diversi", "minimo", "massimo" e, per le colonne di numeri, anche "somma", "media", "mediana" e "deviazione" (deviazione standard).

.tabella_incrociata(righe, colonne, valori = nulla, calcolo = "somma")#

Una tabella pivot (a doppia entrata).

Una riga per ogni valore della colonna righe, una colonna per ogni valore della colonna colonne (nell'ordine in cui compaiono); nelle celle il calcolo sulla colonna valori (senza valori conta le righe).

.togli_colonne(colonne...)#

Una tabella senza le colonne indicate.

.togli_duplicati(colonne = nulla)#

Una tabella senza righe ripetute (resta la prima).

Con colonne due righe sono uguali se sono uguali solo in quelle colonne.

.togli_mancanti(colonne = nulla)#

Una tabella senza le righe che hanno celle vuote.

Con colonne si guardano solo quelle colonne.

.trasforma_colonna(nome, funzione)#

Una tabella in cui ogni cella della colonna è cambiata dalla funzione.

.ultime(quante = 5)#

Una tabella con solo le ultime righe.

.unisci(altra, colonna, modo = "interno")#

Affianca le righe delle due tabelle che hanno lo stesso valore nella colonna.

Modi: "interno" (solo le righe che si trovano in tutte e due), "sinistra" (tutte le righe di questa tabella, anche senza compagna), "completo" (tutte le righe di tutte e due). Le colonne con lo stesso nome nell'altra tabella prendono "_2" in fondo.

.valori_diversi(colonna)#

La lista dei valori di una colonna, ognuno una volta sola (nell'ordine in cui compaiono).

Le celle vuote restano fuori.
