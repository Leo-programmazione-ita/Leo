Suoni e musica

Note, melodie, accordi, suoni e file WAV.

nota(nome, battiti = 1, tempo = 120, ottava = 4, forma = "sinusoide", volume = 0.8)#

Una nota.

Le note sono do re mi fa sol la si, con # o b (fa#, sib) e + o - per l'ottava sopra o sotto.

frequenza_nota(nome, ottava = 4)#

La frequenza della nota in hertz.

tono(frequenza, secondi = 1, forma = "sinusoide", volume = 0.8)#

Un suono di quella frequenza in hertz.

melodia(note, tempo = 120, forma = "sinusoide", volume = 0.8, ottava = 4)#

Una melodia da un testo.

Ogni nota ha la durata attaccata: 1 intero, 2 metà, 4 quarto (un battito), 8 ottavo; "p" è la pausa, "(do mi sol)2" un accordo, "do+" l'ottava sopra.

accordo(note, battiti = 1, tempo = 120, forma = "sinusoide", volume = 0.8, ottava = 4)#

Più note insieme.

note è "do maggiore", "la minore", "sol settima", "do mi sol" o una lista ["do", "mi", "sol"].

rumore(secondi = 1, tipo = "bianco", volume = 0.5)#

Un fruscio; tipi "bianco", "rosa" o "marrone".

silenzio(secondi = 1)#

Un suono muto, utile per fare pause tra altri suoni.

carica_suono(percorso)#

Legge un file WAV e lo restituisce come suono da modificare o unire.

suona(suono, aspetta = falso)#

Fa sentire un suono, una melodia scritta come testo o un file ".wav".

Il programma va avanti subito; con aspetta = vero aspetta la fine. Un nuovo suono ferma il precedente.

suona_file(percorso, aspetta = falso)#

Fa sentire un file WAV.

Per gli MP3 usa il controllo Suono di una finestra.

ferma_suoni()#

Ferma subito il suono che si sta sentendo.

salva_suono(suono, percorso)#

Scrive il suono in un file WAV; restituisce il nome del file.

Oggetto «suono»

Valore Leo di tipo suono: campioni mono tra -1 e 1.

ProprietàSignificato
campioni_al_secondo
durata
volume_massimo

.al_contrario()#

Un suono nuovo che va dalla fine all'inizio.

.con_volume(volume)#

Un suono nuovo più forte o più piano (0 = muto, 1 = pieno).

.dissolvenza(entrata = 0, uscita = 0.5)#

Un suono nuovo che sale e sfuma (secondi).

.insieme(altro)#

Un suono nuovo con i due suoni sovrapposti.

.poi(altro)#

Un suono nuovo: prima questo, poi l'altro.

.ripeti(volte = 2)#

Un suono nuovo che ripete questo tante volte.

.salva(percorso)#

Scrive il suono in un file WAV (vedi salva_suono).

.suona(aspetta = falso)#

Fa sentire il suono (vedi suona).

.taglia(inizio = 0, fine = nulla)#

Il pezzo di suono tra i due istanti (in secondi).
