Costruire un sito con Leo Web

Come si fa e dove trovi le cose nel costruttore di siti. Dalla prima pagina all'esportazione del progetto pronto da pubblicare.

Le due finestre

Leo Web mostra la pagina a sinistra e il codice Leo a destra, sincronizzati. Selezioni un blocco nella pagina e salti alla riga che lo crea; cambi il codice e la pagina si aggiorna. Lavori dal lato che preferisci.

La tua prima pagina

Ogni pagina è una serie di blocchi, uno sotto l'altro. Nel codice è il tipo pagina con i suoi metodi, ed è proprio il codice che il costruttore scrive per te:

variabile p = pagina("Home")
p.titolo("Benvenuti")
p.paragrafo("Questo è il mio primo sito con Leo.")
p.pulsante("Scrivici", "contatti.html")
p.salva("index.html")

I blocchi sono nella tavolozza: titolo, sottotitolo, sezione, testo, immagine, galleria, slider, mappa, collegamento, pulsante, elenco, elenco numerato, tabella, citazione, codice, separatore e piè di pagina. Un sito può avere più pagine: le aggiungi dalla barra delle pagine e le colleghi con pulsanti e collegamenti.

Scrivere il codice a mano

Puoi anche modificare direttamente il codice Leo della pagina: aggiungi una riga come p.citazione("…"), cambi un testo o sposti un blocco, e la pagina si aggiorna. Finché il codice non è un blocco che il costruttore conosce, la pagina resta com'era e Leo te lo segnala: non perdi niente. (Le pagine con blocchi dati si modificano dal costruttore.)

I mattoni

Nel menu Modifica → Altro → Inserisci mattone trovi blocchi di codice pronti con le funzioni del web, divisi per argomento:

  • Scaricare dal web: scaricare una pagina, dati JSON o un file, inviare dati (POST), controllare se c'è internet.
  • Fare una pagina: creare e salvare una pagina.
  • Server e indirizzi: creare un piccolo server web, aggiungere una rotta, avviarlo, scomporre un indirizzo.
  • Pubblicare: pubblicare il sito su GitHub.

Un clic e il codice entra al cursore, con i punti da completare già evidenziati: con Tab passi da uno all'altro.

Il compilatore sceglie la tecnologia

Non scrivi HTML, CSS o JavaScript: li genera Leo da ciò che hai costruito.

  • Ogni pagina diventa HTML, con un unico foglio di stile style.css per tutto il sito.
  • Se un blocco ha bisogno di muoversi (uno slider, una lista con ricerca e ordinamento, un modulo) Leo aggiunge script.js; altrimenti il sito resta senza JavaScript.
  • Per i motori di ricerca prepara anche sitemap.xml.

Siti con dati (nella Suite)

Nella Suite, dove Web e Dati lavorano insieme, la tavolozza ha in più tre blocchi che usano un database vero: Lista da dataset (mostra le righe di una tabella), Modulo contatti (salva quello che scrivono i visitatori) e Gestione dati (aggiungere, modificare e togliere righe). Le query sono sempre preparate, i moduli hanno un filtro antispam e il database non si scarica dal sito.

Quando esporti un sito con dati, Leo ti chiede dove lo pubblicherai:

  • PHP — per l'hosting classico: carichi la cartella e funziona subito. È la scelta proposta.
  • Python (Flask) — un'app autonoma con app.py: pip install -r requirements.txt e poi python app.py.
  • Node.js — un'app autonoma con server.js, senza pacchetti da installare (serve Node 22.5 o più recente): node server.js.
  • Statico — solo pagine: le liste sono una fotografia di quel momento e i moduli non inviano.

Con PHP, Python e Node le liste si aggiornano da sole quando cambiano i dati, senza ricompilare. Né l'app Python né quella Node hanno bisogno di Leo per girare.

Nell'edizione Leo Web da sola questi blocchi non ci sono, perché manca un progetto Dati a cui collegarsi: il sito esce sempre come pagine statiche, pronte per qualunque hosting.

Esportare il progetto

Con Esegui → Esporta sito web scegli una cartella e ottieni il sito completo: le pagine, style.css, le immagini nella cartella immagini/, gli eventuali script e, per i siti con dati, il server scelto con il suo database. Leo comprime HTML e CSS e prepara anche un file ZIP da caricare in un colpo solo. Alla fine ti dice come avviarlo.

Dove trovo le cose

  • Blocchi: la tavolozza del costruttore.
  • Proprietà del blocco (testo, indirizzo, immagine): il pannello a destra.
  • Codice Leo: accanto alla pagina, modificabile.
  • Mattoni: Modifica → Altro → Inserisci mattone.
  • Esporta: menu Esegui → Esporta sito web.
