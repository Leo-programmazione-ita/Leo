Costruire un sito con Leo Web

Come si fa e dove trovi le cose nel costruttore di siti. Dalla prima pagina all'esportazione del progetto pronto da pubblicare.

Le due finestre

Leo Web mostra la pagina a sinistra e il codice Leo a destra, sincronizzati. Selezioni un blocco nella pagina e salti alla riga che lo crea; cambi il codice e la pagina si aggiorna. Lavori dal lato che preferisci.

La tua prima pagina

Una pagina si costruisce pezzo per pezzo con il tipo pagina e i suoi metodi:

variabile p = pagina("Il mio sito")
p.titolo("Benvenuto")
p.paragrafo("Questo è il mio primo sito con Leo.")
p.immagine("foto.jpg")
p.salva("index.html")

Trovi tutti i blocchi nella casella a sinistra: titolo, sottotitolo, sezione, paragrafo, immagine, collegamento, pulsante, elenco, tabella, citazione, codice.

Il compilatore sceglie la tecnologia

Non decidi tu HTML, CSS, PHP o JavaScript: lo capisce Leo Web da ciò che hai scritto.

  • Una pagina di contenuti → HTML + CSS.
  • Un modulo che salva dati → PHP con query preparate (sicure).
  • Una ricerca o un controllo nella pagina → JavaScript.

Usare i dati di Leo Dati

Per mostrare dati veri, dichiara nel progetto.toml cosa usi; poi il nome è pronto nel codice.

[[usa]]
progetto    = "magazzino"
interfaccia = "prodotti"
come        = "catalogo"
variabile p = pagina("Catalogo")
p.mostra(catalogo)
p.salva("index.html")

Esportare il progetto

Con Esporta ottieni una cartella web completa — index.html, le altre pagine, stile.css, gli script e gli eventuali file PHP — pronta da caricare sul tuo hosting.

Dove trovo le cose

  • Blocchi: casella a sinistra.
  • Proprietà del blocco (testo, colore, link): pannello a destra.
  • Codice Leo: finestra accanto alla pagina.
  • Anteprima dal vivo: si aggiorna a ogni modifica.
  • Esporta: nel menu del progetto.
