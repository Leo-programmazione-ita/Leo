Installazione e primo avvio

In dieci minuti Leo è sul tuo computer e Leo Studio è aperto davanti a te. Non serve essere amministratori e non serve installare Python: il programma di installazione contiene già tutto.

  • 6 minuti di lettura
  • Livello: base
  • 1 esempio verificato

Che cosa ti serve#

  • Un computer con Windows 10 o Windows 11 a 64 bit. Leo Studio e i programmi con le finestre usano la libreria grafica Qt, che richiede un sistema a 64 bit.
  • Una connessione a Internet per scaricare il programma di installazione: un file solo che si chiama Setup_Leo_ seguito dal numero di versione (per esempio Setup_Leo_0.1.0.exe).
  • Nessun diritto di amministratore. Leo si installa solo per il tuo utente, nella tua cartella personale: non tocca le impostazioni del computer.
  • Nessun Python. Dentro il programma di installazione ci sono già Python, la grafica, Leo Studio, gli esempi e la guida.

Nota

Usi macOS o Linux? Leo funziona anche lì, ma senza programma di installazione: leggi più sotto Installazione con Python.

Scaricare Leo#

  1. Apri la pagina Scarica Leo di questo sito e premi il pulsante Scarica Leo.

  2. Il browser salva il file Setup_Leo_….exe, di solito nella cartella Download.

  3. Fai doppio clic sul file scaricato.

L'avviso blu di Windows (SmartScreen)#

La prima volta che avvii un programma appena scaricato da Internet, Windows può mostrare una finestra blu con scritto «Windows ha protetto il PC — App non riconosciuta». Non è un errore: Windows avvisa così per tutti i programmi nuovi che non ha ancora visto su molti computer.

  1. Nella finestra blu fai clic su Ulteriori informazioni.

  2. Controlla che il nome del file sia Setup_Leo_….exe.

  3. Premi Esegui comunque.

Attenzione

Fallo solo per il file scaricato dal sito ufficiale di Leo. Se hai ricevuto il programma di installazione da qualcun altro, per esempio per email o su una chiavetta, scaricalo di nuovo dal sito.

L'installazione in cinque passi#

Il programma di installazione è una finestra nera e rossa con lo stemma del leone. Ti accompagna in cinque passi; puoi sempre tornare indietro.

  1. Benvenuto. Mostra lo spazio necessario sul disco. Se Leo è già installato, ti dice che verrà aggiornato.

  2. Licenza. Leggi il contratto di licenza e spunta Accetto per andare avanti.

  3. Cartella. Leo propone C:\Users\tuonome\AppData\Local\Programs\Leo. Va benissimo così: è la cartella dei programmi del tuo utente. Le cartelle di sistema come C:\Program Files non si possono scegliere.

  4. Opzioni (tutte attive di serie):

    • il collegamento Leo Studio sul Desktop;
    • la cartella Leo nel menu Start, con Leo Studio, la riga di comando e Disinstalla Leo;
    • i file .leo e .maschera si aprono con Leo Studio (con il tasto destro su un .leo trovi anche Esegui con Leo);
    • il comando leo funziona in ogni Prompt dei comandi aperto dopo l'installazione.

  5. Installazione. Una barra mostra l'avanzamento; se la interrompi, quello che era già stato copiato viene tolto. Alla fine lascia spuntato Avvia Leo Studio e premi Fine.

Suggerimento

Se in passato hai scelto un altro programma per i file .leo con Apri con → Usa sempre questa app, Windows continua a usare quello. Lo cambi da Impostazioni → App → App predefinite.

Il primo avvio di Leo Studio#

Apri Leo Studio con il collegamento sul Desktop o dal menu Start. Mentre si carica compare lo stemma del leone con una sottile barra d'avanzamento; poi si apre la schermata di benvenuto, che occupa tutta la finestra. Qui trovi:

  • i progetti recenti, da riaprire con un doppio clic (all'inizio l'elenco è vuoto);
  • quattro modelli pronti da provare subito con F5:
ModelloChe cosa contiene
Applicazione vuotauna finestra pronta, senza controlli: il punto di partenza per un progetto nuovo
Calcolatricedue numeri, quattro operazioni e la gestione degli errori di inserimento
Gioco 2Dun bersaglio che si muove, il punteggio e una partita a tempo
Disegno vettoriale con la Tartarugapoligoni, stelle e spirali disegnati con il codice

Al primo avvio una guida in tre passi ti accompagna nel primo programma: Inserisci un pulsante, Scrivi il gestore del clic, Esegui il programma. Puoi ripeterla quando vuoi da Aiuto → Primo avvio guidato. Lo stesso percorso, spiegato con calma, è nella sezione Il tuo primo programma.

In basso a destra vedi «Versione gratuita»: questa versione di Leo è completa e senza scadenza, senza chiave da inserire. Tutto sulla licenza e sugli aggiornamenti futuri è nella sezione Licenza e aggiornamenti.

Installazione con Python (macOS, Linux e sviluppo)#

Esiste anche la versione cartella di Leo, che usa il Python installato sul computer. Serve su macOS e Linux e su Windows a chi vuole creare file .exe dai propri programmi (vedi Creare il .exe): la creazione degli eseguibili ha bisogno di Python e di PyInstaller.

Su Windows#

  1. Installa Python 3.10 o successivo da python.org. Prima di premere Install Now spunta la casella Add python.exe to PATH.

  2. Copia la cartella di Leo dove preferisci (per esempio C:\Users\tuonome\Leo), evitando le cartelle protette come C:\Program Files.

  3. Nella cartella di Leo fai doppio clic su installa.bat. Si apre una finestra nera che chiede conferma prima di ogni passo (premi Invio per dire sì): cerca Python, crea l'ambiente .venv, installa PySide6 (circa 100 MB), associa i file .leo e crea i collegamenti Leo Studio, Leo - riga di comando e Disinstalla Leo.

Suggerimento

Per rispondere sì a tutto senza domande: installa.bat -SiATutto. L'installatore cambia la politica di PowerShell solo per quel processo: le impostazioni di sicurezza del computer restano come sono.

Dalla cartella di Leo, in un terminale:

L'interprete di Leo usa solo la libreria standard di Python: i programmi senza finestre funzionano anche senza PySide6.

Aggiornare e disinstallare#

Aggiornare è semplice: scarica e avvia il programma di installazione della versione nuova. Propone la stessa cartella, sostituisce i file e aggiorna Leo in Impostazioni → App. Leo Studio deve essere chiuso.

Disinstallare: Impostazioni → App → App installate → Leo → Disinstalla, oppure menu Start → Leo → Disinstalla Leo. Vengono tolti i file installati, i collegamenti, le associazioni dei file e il comando leo.

I tuoi progetti sono al sicuro

La disinstallazione non tocca mai i tuoi progetti: né la cartella Leo del tuo utente, né i file che hai aggiunto tu. Toglie soltanto i file che aveva installato.
